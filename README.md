# BuddyDuck — спортивная одежда

Демо интернет-магазина (аналог Gymshark) — третий проект портфолио. Логотип — маленькая резиновая уточка с красным клювом.

## Стек

Чистый HTML / CSS / JavaScript — без фреймворков и сборки.

## Возможности

- Каталог из `data/products.json`: 12 товаров, категории, бейджи («хит», «новинка», «−20%»)
- Поиск по названию, фильтр-категории, сортировка (популярные / дешевле / дороже / рейтинг)
- Корзина: выдвижная панель, количество +/−, удаление, итог, сохранение в localStorage
- Оформление заказа: форма (имя, телефон, адрес), экран подтверждения с номером заказа
- Дизайн: минимализм в духе Джони Айва — нежно-голубой фон, тёмно-синий текст и кнопки, белые карточки, воздух и мягкие тени
- Полностью на русском, адаптивная вёрстка

## Запуск локально

```bash
cd store
python3 -m http.server 8000
# открыть http://localhost:8000
```
